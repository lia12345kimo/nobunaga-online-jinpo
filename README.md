# 信長之野望 Online 英傑陣法計算

《信長之野望 Online》的英傑陣法計算工具。勾選持有的英傑，找出因緣最多、連線最多或能力最高的六人排法。

## 規則

六名英傑排成一圈，每相鄰三人各提供一個因子，即成立一個因緣。一圈有六組相鄰三人，一組可以同時成立好幾個因緣。

## 計算方式

- 30 人以內：逐一窮舉所有排法，保證是最佳解（「連線最多」除外）。
- 人數更多或「連線最多」：先以模擬退火選人，六人的 60 種排法再逐一比較。不保證是絕對最佳解。

## 資料來源

英傑資料與因緣規則取自 [英傑レベル20ステータス（お汀さん）](https://imagawan.yoshi-moto.com/eiketsu20.html)，為日版名稱與信賴度 Lv20 數值。

- 「能力」是六人 Lv20 數值的合計，只供比較用，不等於遊戲顯示的陣法加成。
- 「コスト」與遊戲中的「陣型價值」不同，目前沒有套用價值上限。
- 因緣「柔能制剛」要求的因子「陰」目前沒有任何英傑擁有，這條不會成立。
